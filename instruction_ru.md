# SFM Community Patcher — Инструкция по установке

Универсальный патчер для **Source Filmmaker** (Steam). Автоматически расширяет внутренние лимиты памяти движка, устраняет частые вылеты и настраивает продвинутую графическую связку **DXVK (Vulkan)** + **ReShade** для максимальной стабильности и красивой картинки.

---

## Что делает патчер

| Функция | Результат |
|---------|-----------|
| **Оптимизация Hunk** | Полностью решает проблему вылетов `Engine hunk overflow!` на больших и тяжелых картах. |
| **Расширение RBTree** | Снимает 16-битный лимит движка на количество моделей, костей и ключей анимации (`CUtlRBTree overflow!`). |
| **Обход ограничений** | Разблокирует доступ к скрытым кинематографическим консольным командам без принудительного включения читов. |
| **Рендер через Vulkan** | Переводит устаревший Direct3D 9 на современный API Vulkan с помощью DXVK, убирая фризы и статоры. |
| **Интеграция ReShade** | Позволяет использовать любые современные эффекты постобработки прямо внутри обновленного движка.

> **Безопасность:** Все изменения вносятся точечно на уровне байт. Размеры оригинальных файлов не меняются. Автоматическая резервная копия оригинала всегда сохраняется в папку `bin\backups\`.

---

## Требования к системе
* Windows 10 / 11 (64-bit)
* Установленный **Source Filmmaker** (Steam)
* Компоненты **Python 3**, добавленные в переменные среды PATH (для работы скриптов патчера)

---

## Шаг 1. Распаковка патчера

Распакуйте все файлы из архива патчера напрямую в корневую папку **`game`** вашего Source Filmmaker (туда, где находится файл `sfm.exe`):
SourceFilmmaker\game

├── sfm.exe
├── patch_sfm.bat
├── setup_reshade_dxvk.bat
├── instruction_ru.md
├── instruction_eng.md
└── sfm_patcher\


---

## Шаг 2. Установка графических компонентов (DXVK и ReShade)

1. **DXVK:** Скачайте актуальный релиз **DXVK** (вам нужна 32-битная сборка, папка `x32`). Возьмите из неё файл `d3d9.dll`, скопируйте его в папку `game\bin\` и переименуйте в **`d3d9_vlk.dll`**.
2. **ReShade:** Установите ReShade для Source Filmmaker, выбрав Direct3D 9. Убедитесь, что в папке `game\bin\` появился оригинальный файл `d3d9.dll` от ReShade.

---

## Шаг 3. Запуск и автоматическая настройка

1. **Полностью закройте Source Filmmaker** перед началом установки.
2. Запустите файл **`patch_sfm.bat`** от имени администратора.
3. В появившемся удобном меню выберите **Пункт 1** для автоматического применения всех оптимизаций движка и интеграции библиотек.
4. *(Опционально)* Если вы хотите проверить файлы перед записью, используйте **Пункт 2 (Dry-Run)** для безопасной симуляции патчинга.

Патчер автоматически создаст правильную цепочку вызовов:
Запуск игры → Загрузка ReShade (d3d9.dll) → Высокопроизводительный Vulkan (d3d9_vlk.dll)


---

## Шаг 4. Проверка успешности установки

Запустите Source Filmmaker и проверьте следующие элементы:
* В корневой папке `game` появился лог-файл `sfm_d3d9.log` с упоминанием вашей видеокарты и версии Vulkan.
* По нажатию клавиши **Home** (или вашей кастомной кнопки) внутри SFM открывается полноценное меню оверлея ReShade.
* Тяжелые сцены и карты с большим количеством геометрии больше не вызывают мгновенный вылет движка.

---

## Восстановление и откат изменений

Если вам потребуется вернуть чистую Steam-версию файлов:
1. Запустите **`patch_sfm.bat`** и выберите **Пункт 3 (Restore Original DLLs)**. Оригинальные файлы мгновенно вернутся из бэкапа.
2. В любой момент вы также можете зайти в свойства игры в Steam и выбрать *«Проверить целостность игровых файлов»*.
